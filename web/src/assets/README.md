# Brand assets

`icor-logo-white.svg` is a local wrapper around the exact pixels from ICOR SA's
official white logo at `https://icor.be/images/icor-blanc.png`, retrieved on
2026-09-08. The source PNG is 151 x 45 pixels and has SHA-256
`55c76bf6c858444e0eaf3889e4f737b928ffedc1fc5652563a9d585d74efd95c`.

The wrapper avoids a runtime dependency on the public website. Preserve the logo's
aspect ratio and do not recolour, redraw, or separate its wordmark and tagline.
